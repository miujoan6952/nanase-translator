How it works

Letters are swapped one by one, so “Aku capek” becomes Nåsâåasoå Månåsoånsåsâå. Spaces, punctuation and symbols stay as they are. Every letter code ends in å and every digit code ends in í, which is why Nanase can be turned back into text exactly, apart from the original capitals and accents.
